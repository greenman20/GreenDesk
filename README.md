# 🖥️ Remote Desktop - Приложение для удаленного доступа

Простое и функциональное приложение для удаленного доступа к рабочему столу, аналог AnyDesk, написанное на Python.

## ✨ Возможности

- 📺 Захват и передача экрана в реальном времени
- 🖱️ Удаленное управление мышью
- ⌨️ Удаленное управление клавиатурой
- 🎯 Простой графический интерфейс
- ⚡ Настраиваемое качество и FPS
- 🔧 Легкая настройка

## 📋 Требования

- Python 3.7+
- Linux/Windows/macOS

## 🚀 Установка

### Вариант 1: Использование готовых исполняемых файлов (рекомендуется)

Скачайте готовые исполняемые файлы из раздела Releases и запустите:
- **Linux/macOS**: `./RemoteDesktop-Launcher`
- **Windows**: `RemoteDesktop-Launcher.exe`

### Вариант 2: Из исходного кода

1. Клонируйте репозиторий или скачайте файлы:
```bash
git clone <repository-url>
cd remote-desktop
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

### Вариант 3: Собрать самостоятельно

```bash
# Установить PyInstaller
pip install -r requirements.txt

# Собрать исполняемые файлы
./build_all.sh  # Linux/macOS
# или
build.bat       # Windows
```

Подробнее см. [BUILD.md](BUILD.md)

## 📖 Использование

### Вариант 1: Графический интерфейс (рекомендуется)

Запустите launcher для удобного выбора режима:

```bash
python3 launcher.py
```

В графическом интерфейсе:
- Выберите **Host** если хотите предоставить доступ к своему компьютеру
- Выберите **Viewer** если хотите подключиться к другому компьютеру

### Вариант 2: Командная строка

#### Запуск Host (сервера)

На компьютере, к которому нужен доступ:

```bash
python3 host.py
```

Программа запросит:
- IP адрес для прослушивания (оставьте пустым для 0.0.0.0)
- Порт (по умолчанию 5555)

**Важно**: Узнайте свой IP адрес командой:
```bash
# Linux/macOS
ifconfig
# или
ip addr

# Windows
ipconfig
```

#### Запуск Viewer (клиента)

На компьютере, с которого нужно подключиться:

```bash
python3 viewer.py
```

Программа запросит:
- IP адрес сервера (Host)
- Порт (по умолчанию 5555)

## ⚙️ Настройка

Отредактируйте файл `config.py` для изменения параметров:

```python
# Сетевые настройки
DEFAULT_PORT = 5555           # Порт по умолчанию

# Настройки качества изображения
SCREEN_QUALITY = 70           # Качество JPEG (0-100)
SCREEN_SCALE = 1.0           # Масштаб экрана (0.5 = 50%)
FPS = 30                     # Кадров в секунду

# Цвета интерфейса
BACKGROUND_COLOR = "#1e1e1e"
BUTTON_COLOR = "#0078d4"
TEXT_COLOR = "#ffffff"
```

### Рекомендации по настройке:

- **Медленное соединение**: Уменьшите `SCREEN_QUALITY` до 50-60 и `FPS` до 15-20
- **Быстрое соединение**: Увеличьте `SCREEN_QUALITY` до 85-90 и `FPS` до 30-60
- **Большой экран**: Уменьшите `SCREEN_SCALE` до 0.75 или 0.5

## 🔒 Безопасность

## 🌐 Настройка сети

### Локальная сеть (LAN)
Если оба компьютера в одной сети - просто используйте локальный IP адрес.

### Через интернет
1. Настройте проброс порта (port forwarding) на роутере Host
2. Используйте внешний IP адрес роутера для подключения
3. Или используйте VPN/Hamachi/ZeroTier для создания виртуальной сети

### Проверка доступности порта

На Host проверьте, что порт открыт:

```bash
# Linux
sudo ufw allow 5555/tcp

# Windows
# Откройте порт в Windows Firewall
```

## 🎮 Управление

В режиме Viewer:
- Двигайте мышь для управления курсором
- Левая/правая кнопка мыши работает как обычно
- Клавиатура работает в окне просмотра
- Колесо мыши для прокрутки

## 🐛 Решение проблем

### Ошибка "Connection refused"
- Проверьте, что Host запущен
- Проверьте правильность IP адреса
- Проверьте, что порт не заблокирован файерволом

### Низкий FPS или задержки
- Уменьшите `SCREEN_QUALITY` в config.py
- Уменьшите `SCREEN_SCALE` в config.py
- Проверьте скорость интернет-соединения

### "PIL cannot identify image file"
- Обновите Pillow: `pip install --upgrade pillow`

### Ошибки с pynput на Linux
Установите дополнительные зависимости:
```bash
sudo apt-get install python3-xlib
```
