2️⃣  HOST (СЕРВЕР) - Предоставить доступ к своему экрану
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    Программа спросит:

    > Введите порт: [нажмите Enter для 5555]

    Программа покажет ваш IP адрес - сообщите его человеку,
    который будет подключаться (Viewer).


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3️⃣  VIEWER (КЛИЕНТ) - Подключиться к чужому экрану
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    $ ./dist/RemoteDesktop-Viewer

    Программа спросит:
    > Введите IP адрес сервера: [IP компьютера с Host]
    > Введите порт: [нажмите Enter для 5555]

    Откроется окно с удаленным экраном.
    Управляйте мышью и клавиатурой как обычно.


================================================================================
                        🧪 БЫСТРЫЙ ТЕСТ
================================================================================

Протестируйте на одном компьютере:

Шаг 1 - Откройте первый терминал:
    $ cd /workspace
    $ ./dist/RemoteDesktop-Host
    > IP: [просто нажмите Enter]
    > Port: [просто нажмите Enter]

Шаг 2 - Откройте второй терминал:
    $ cd /workspace
    $ ./dist/RemoteDesktop-Viewer
    > IP: 127.0.0.1
    > Port: 5555

Шаг 3 - В окне Viewer вы увидите экран!


================================================================================
                        🌐 ИСПОЛЬЗОВАНИЕ В СЕТИ
================================================================================

КОМПЬЮТЕР A (Host - к которому подключаются):

1. Узнайте свой IP адрес:
   $ ip addr | grep "inet " | grep -v 127.0.0.1
   или
   $ ifconfig

2. Запустите Host:
   $ ./dist/RemoteDesktop-Host
   > IP: 0.0.0.0  (или ваш локальный IP)
   > Port: 5555

3. Сообщите IP адрес пользователю Viewer


КОМПЬЮТЕР B (Viewer - который подключается):

1. Запустите Viewer:
   $ ./dist/RemoteDesktop-Viewer
   > IP: [IP адрес компьютера A]
   > Port: 5555

2. Теперь вы видите экран компьютера A!


================================================================================
                        🔥 ФАЙЕРВОЛ
================================================================================

⚠️  ВАЖНО: Откройте порт в файерволе на Host!

Ubuntu/Debian:
    $ sudo ufw allow 5555/tcp
    $ sudo ufw reload

RedHat/CentOS:
    $ sudo firewall-cmd --add-port=5555/tcp --permanent
    $ sudo firewall-cmd --reload


================================================================================
                        ⚙️ НАСТРОЙКИ
================================================================================

Если хотите изменить качество/FPS:

1. Отредактируйте config.py:
   $ nano config.py

2. Измените параметры:
   SCREEN_QUALITY = 70    # Качество JPEG (0-100)
   FPS = 30              # Кадров в секунду
   SCREEN_SCALE = 1.0    # Масштаб экрана

3. Пересоберите:
   $ python3 -m PyInstaller --clean host.spec
   $ python3 -m PyInstaller --clean viewer.spec


================================================================================
                        🐛 ПРОБЛЕМЫ?
================================================================================

ОШИБКА: "Permission denied"
    $ chmod +x dist/RemoteDesktop-*

ОШИБКА: "Connection refused"
    • Проверьте, что Host запущен
    • Проверьте IP адрес
    • Проверьте файервол (sudo ufw allow 5555/tcp)

ОШИБКА: "tkinter installation is broken" (Launcher)
    • Используйте Host/Viewer напрямую
    • Или установите: sudo apt-get install python3-tk
    • И установите X server: export DISPLAY=:0

НИЗКИЙ FPS / ЛАГИ:
    • Уменьшите SCREEN_QUALITY в config.py
    • Уменьшите FPS
    • Уменьшите SCREEN_SCALE до 0.75 или 0.5

НЕ РАБОТАЕТ КЛАВИАТУРА/МЫШЬ НА HOST:
    • Linux может требовать sudo для pynput
    • Запустите: sudo ./dist/RemoteDesktop-Host
