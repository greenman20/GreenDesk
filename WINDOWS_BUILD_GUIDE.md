# 🪟 Инструкция по сборке для Windows

## Шаг 1: Установка Python

1. Скачайте Python с официального сайта:
   https://www.python.org/downloads/

2. При установке **ОБЯЗАТЕЛЬНО** поставьте галочку:
   ☑️ "Add Python to PATH"

3. Нажмите "Install Now"

## Шаг 2: Проверка установки

Откройте командную строку (Win + R → cmd) и проверьте:

```cmd
python --version
```

Должно показать: `Python 3.x.x`

## Шаг 3: Скачивание проекта

Скопируйте все файлы проекта на Windows:
- config.py
- host.py
- viewer.py
- launcher.py
- host.spec
- viewer.spec
- launcher.spec
- requirements.txt
- build.bat

Например, в папку: `C:\RemoteDesktop\`

## Шаг 4: Установка зависимостей

Откройте командную строку в папке проекта:

```cmd
cd C:\RemoteDesktop
pip install -r requirements.txt
```

Дождитесь установки всех библиотек (~5 минут).

## Шаг 5: Запуск автоматической сборки

Просто запустите готовый скрипт:

```cmd
build.bat
```

Или двойным кликом на файл `build.bat` в Проводнике.

### Выберите опцию:
- `1` - Собрать только Host
- `2` - Собрать только Viewer
- `3` - Собрать только Launcher
- `4` - Собрать ВСЁ (рекомендуется)

## Шаг 6: Готово!

После сборки в папке `dist\` появятся файлы:

```
C:\RemoteDesktop\dist\
├── RemoteDesktop-Host.exe         (~80-120 MB)
├── RemoteDesktop-Viewer.exe       (~80-120 MB)
└── RemoteDesktop-Launcher.exe     (~80-120 MB)
```

Эти `.exe` файлы можно запускать на любом Windows без установки Python!

## 🚀 Как использовать на Windows

### Запуск Host (Сервер)

1. Откройте командную строку:
   - `Win + R` → `cmd`

2. Перейдите в папку:
   ```cmd
   cd C:\RemoteDesktop\dist
   ```

3. Запустите Host:
   ```cmd
   RemoteDesktop-Host.exe
   ```

4. Введите настройки:
   - IP: [нажмите Enter для 0.0.0.0]
   - Port: [нажмите Enter для 5555]

5. Узнайте свой IP:
   ```cmd
   ipconfig
   ```
   Ищите "IPv4 Address" в разделе вашего адаптера (WiFi или Ethernet).

### Запуск Viewer (Клиент)

1. Откройте командную строку:
   ```cmd
   cd C:\RemoteDesktop\dist
   ```

2. Запустите Viewer:
   ```cmd
   RemoteDesktop-Viewer.exe
   ```

3. Введите:
   - IP адрес сервера (например: `192.168.1.100`)
   - Port: `5555`

### Или используйте Launcher (GUI)

Просто **двойным кликом** запустите:
```
RemoteDesktop-Launcher.exe
```

## 🛡️ Настройка файервола Windows

Windows может заблокировать подключения. Разрешите доступ:

### Способ 1: Через интерфейс

При первом запуске Host появится окно:
- "Брандмауэр Windows заблокировал некоторые функции"
- Нажмите **"Разрешить доступ"**

### Способ 2: Через командную строку (от Администратора)

```cmd
netsh advfirewall firewall add rule name="RemoteDesktop Host" dir=in action=allow protocol=TCP localport=5555
```

### Способ 3: Ручная настройка

1. Откройте "Панель управления"
2. "Брандмауэр Windows"
3. "Дополнительные параметры"
4. "Правила для входящих подключений"
5. "Создать правило..."
6. Выберите "Для порта" → TCP → 5555

## 🐛 Возможные проблемы на Windows

### Ошибка: "python не является внутренней командой"

**Решение:** Python не добавлен в PATH. Переустановите Python с галочкой "Add to PATH".

### Ошибка: "pyinstaller не найден"

**Решение:**
```cmd
pip install --upgrade pyinstaller
```

### Антивирус удаляет .exe файлы

**Решение:**
1. Добавьте папку `dist\` в исключения антивируса
2. Временно отключите антивирус во время сборки
3. Это ложное срабатывание - файлы безопасны

### Ошибка: "No module named 'tkinter'"

**Решение:** При установке Python выберите "Custom Installation" и включите "tcl/tk and IDLE".

### Launcher не открывается

**Решение:** Запустите через командную строку чтобы увидеть ошибки:
```cmd
RemoteDesktop-Launcher.exe
```

## 📦 Распространение Windows версии

После сборки можно создать ZIP архив:

1. Скопируйте папку `dist\` и файл `README.md`
2. Сжать в ZIP
3. Распространяйте!

Пользователям нужно только:
1. Распаковать ZIP
2. Запустить .exe файлы
3. Разрешить в файерволе

**Python устанавливать НЕ нужно!**
