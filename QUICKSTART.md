# 🚀 Быстрый старт

## За 3 шага к удаленному подключению

### Шаг 1: Установка

```bash
# Установите зависимости
pip install -r requirements.txt
```

### Шаг 2: Запуск Host (на удаленном компьютере)

**Способ A - GUI (проще)**:
```bash
python3 launcher.py
# Нажмите "Host (Сервер)" и "Запустить Host"
```

**Способ B - Консоль**:
```bash
./run_host.sh
# или
python3 host.py
```

📝 **Запомните IP адрес**, который покажет программа!

### Шаг 3: Подключение с Viewer (на вашем компьютере)

**Способ A - GUI (проще)**:
```bash
python3 launcher.py
# Нажмите "Viewer (Клиент)"
# Введите IP адрес Host
# Нажмите "Подключиться"
```

**Способ B - Консоль**:
```bash
./run_viewer.sh
# или
python3 viewer.py
# Введите IP адрес Host
```

## ✅ Готово!

Теперь вы видите экран удаленного компьютера и можете управлять им!

---

## 🔧 Частые проблемы

### "Connection refused"
→ Проверьте, что Host запущен и IP адрес правильный

### Низкий FPS
→ Откройте `config.py` и измените:
```python
SCREEN_QUALITY = 50  # Было 70
FPS = 20             # Было 30
```

### Не работает на Linux
→ Установите дополнительные пакеты:
```bash
sudo apt-get install python3-tk python3-xlib scrot
```
