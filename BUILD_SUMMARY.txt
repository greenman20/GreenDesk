СПОСОБ 1: Автоматическая сборка (рекомендуется)
------------------------------------------------
Linux/macOS:
    $ chmod +x build_all.sh
    $ ./build_all.sh

Windows:
    > build.bat
    > Выберите опцию "4"


СПОСОБ 2: Интерактивная сборка
--------------------------------
Linux/macOS:
    $ ./build.sh

Windows:
    > build.bat

Выберите что собрать (1-4):
    1 - Host (Сервер)
    2 - Viewer (Клиент)
    3 - Launcher (GUI)
    4 - Все приложения


СПОСОБ 3: Ручная сборка через PyInstaller
------------------------------------------
    $ pip install pyinstaller
    $ pyinstaller --clean host.spec
    $ pyinstaller --clean viewer.spec
    $ pyinstaller --clean launcher.spec

После сборки в папке dist/ появятся:

Linux/macOS:
    dist/RemoteDesktop-Host
    dist/RemoteDesktop-Viewer
    dist/RemoteDesktop-Launcher

Windows:
    dist\RemoteDesktop-Host.exe
    dist\RemoteDesktop-Viewer.exe
    dist\RemoteDesktop-Launcher.exe

Размеры: ~80-120 MB каждый файл

================================================================================
                        БЫСТРЫЙ ТЕСТ
================================================================================

После сборки протестируйте:

1. Запустите Host:
   $ ./dist/RemoteDesktop-Host

2. В другом терминале запустите Viewer:
   $ ./dist/RemoteDesktop-Viewer
   > Введите: 127.0.0.1 (для локального теста)
   > Порт: 5555

3. Проверьте, что экран отображается и мышь/клавиатура работают

    $ pyinstaller --clean --onefile host.spec

Сборка без консоли (только GUI):

Сборка с иконкой:
    $ pyinstaller --clean --icon=icon.ico host.spec

================================================================================
                        РЕШЕНИЕ ПРОБЛЕМ
================================================================================

1. Ошибка "pyinstaller: command not found"
   → pip install pyinstaller

2. Ошибка "Failed to execute script"
   → Проверьте логи в build/ или запустите с console=True

3. Большой размер файла
   → Используйте виртуальное окружение с минимальными зависимостями
   → Добавьте excludes в .spec файл

4. Долгий запуск
   → Это нормально для --onefile режима
   → Используйте --onedir для быстрого запуска

5. Антивирус блокирует
   → Добавьте в исключения
   → Подпишите файл цифровой подписью
