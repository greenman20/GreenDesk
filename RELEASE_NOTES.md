# 📦 Release Notes

## Version 1.0.0 - Initial Release

### 🎉 Что включено

Это первый релиз Remote Desktop - приложения для удаленного доступа к рабочему столу.

### ✨ Основные возможности

- **Захват экрана в реальном времени** с настраиваемым FPS (до 60)
- **Полное управление мышью**: движение, клики, прокрутка
- **Полное управление клавиатурой**: все клавиши, включая специальные
- **Графический интерфейс (Launcher)** для удобного запуска
- **Настраиваемое качество**: JPEG качество, масштабирование, FPS
- **Кросс-платформенность**: Linux, Windows, macOS

### 📦 Доступные файлы

#### Исполняемые файлы (Standalone)

- **RemoteDesktop-Host** - Серверная часть (предоставляет доступ к экрану)
- **RemoteDesktop-Viewer** - Клиентская часть (подключается к серверу)
- **RemoteDesktop-Launcher** - GUI для удобного запуска

#### Исходный код

- Все Python файлы
- Файлы конфигурации для сборки
- Полная документация

### 🚀 Быстрый старт

#### Для пользователей (готовые исполняемые файлы)

1. Скачайте файл для вашей ОС
2. На компьютере A запустите `RemoteDesktop-Host`
3. На компьютере B запустите `RemoteDesktop-Viewer` и введите IP компьютера A

#### Для разработчиков (из исходников)

```bash
git clone <repository-url>
cd remote-desktop
pip install -r requirements.txt
python3 launcher.py
```

### 📊 Технические характеристики

- **Языки**: Python 3.7+
- **Основные библиотеки**: Pillow, pynput, tkinter
- **Протокол**: TCP сокеты
- **Сжатие**: JPEG
- **Размер**: ~80-120 MB на исполняемый файл
- **Производительность**: 15-60 FPS в зависимости от настроек

### 📝 Известные ограничения

- Нет шифрования трафика (планируется в v1.1.0)
- Нет аутентификации пользователей (планируется в v1.1.0)
- Поддержка только одного монитора
- Нет передачи звука
- Нет передачи файлов

### ⚠️ Важные заметки

1. **Безопасность**: Это базовая реализация. Для production использования рекомендуется добавить шифрование и аутентификацию.

2. **Производительность**: Для медленных соединений уменьшите качество и FPS в `config.py`.

3. **Файервол**: Убедитесь, что порт 5555 (по умолчанию) открыт на Host машине.
