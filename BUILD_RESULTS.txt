⚠️  TKINTER WARNING (Launcher):
    Во время сборки Launcher было предупреждение:
    "tkinter installation is broken. It will be excluded"
    
    Это может означать, что Launcher не будет работать в среде без X server.
    Для GUI приложений на Linux требуется:
    - X server (DISPLAY environment variable)
    - Tkinter установленный в системе
    
    Решение для использования:
    1. Убедитесь что DISPLAY установлен: export DISPLAY=:0
    2. Установите tkinter: sudo apt-get install python3-tk
    3. Используйте Host/Viewer напрямую без Launcher
